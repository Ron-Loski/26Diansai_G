# TJC1060X570 串口屏界面

## 工程配置

- 屏幕型号：`TJC1060X570_011C_I`
- 上位机基础设备定义：`TJC1060X570_011`
- 系列：X5
- 尺寸与分辨率：7.0 英寸，`1024 × 600`
- 显示方向：横屏（0°）
- 串口：`115200, 8N1`

主工程为 `G_Signal_Analyzer_X570.HMI`。它以“周期.HMI”例程的 1024 × 600
页面作为型号兼容底板。例程中的控件仅用于保留正确的设备定义；STM32 上电后会
隐藏这些控件并绘制完整的深色仪表盘，再实时刷新测量文字、时域波形和频谱。

因此编辑器的原始“界面”页不是最终实机效果，最终效果请参考
`G_Signal_Analyzer_X570_preview.png`，并在 MCU 联机或 HMI 调试器收到初始化
命令后查看。

## 接线

| STM32H743 | 串口屏 |
| --- | --- |
| PA2 / USART2_TX | RX |
| PA3 / USART2_RX | TX |
| GND | GND |

屏幕使用满足其额定电流的独立 5 V 电源，并与主控共地。不要使用 STM32 的
3.3 V 引脚给屏幕供电。

## 显示内容

- 时域波形，可触摸切换 1 个周期或 3 个完整周期
- 峰峰值 `Upp`、真有效值 `Urms`、基波频率 `f1`
- 0～500 kHz 正频率电压频谱
- 基波和最多两个谐波的频率、峰值幅度
- 无有效信号时状态点显示红色，有效测量时显示绿色
- 右侧分量区显示基波及最多两个谐波的频率和峰值幅度

## 固件入口

- `Uitls/Inc/hmi_display.h`
- `Uitls/Src/hmi_display.c`

`main.c` 在 USART2 初始化后调用 `HMI_Display_Init()`，每次分析成功后调用
`HMI_Display_Update()`。触摸坐标由 `HMI_Display_Service()` 轮询处理。

## 工程集成说明

本分支不修改 CubeMX/Keil 自动生成的工程配置文件。请在 CubeMX 中确认
USART2 使用 PA2/PA3、异步模式、115200、8N1、无硬件流控，然后重新生成代码。

生成后，在 Keil 的工程分组中手动添加 `Uitls/Src/hmi_display.c`。头文件目录
`Uitls/Inc` 已由现有工程使用；如果本机工程中尚未配置，请在 Keil 的 Include
Paths 中添加该目录。
