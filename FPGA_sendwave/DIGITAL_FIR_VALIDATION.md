# AD9233抽取前数字低通验证

## 数据链

```text
AD9233 25 MSPS
→ 159 taps Q1.17线性相位FIR
→ 13倍抽取
→ 1.923076923 MSPS
→ 4096点缓存
→ 原SPI协议
→ STM32H743
```

SPI数据格式、4096点长度、MCU采样率配置和电压换算均未改变。

## 待上板验证

1. 烧录新SOF，MCU继续使用 `fw=2045` 直采固件。
2. 先测10、250、500 kHz的50 mVpp与250 mVpp单音，确认幅值变化不超过5 mV。
3. 重测已通过的双音和三音，确认分量数、频率与幅值保持正确。
4. 只输入200 mVpp的1、1.1、1.5、2、4、5、10 MHz干扰，均应得到无有效分量。
5. 有效信号叠加上述干扰，比较加入干扰前后的Upp、Urms及各分量幅值，变化应不超过5 mV。
6. 连续运行60秒，要求OTR、CRC、protocol和DMA错误均为0。

数字FIR不能替代ADC之前的模拟抗混叠滤波；高于12.5 MHz并已混叠进通带的输入无法由本FIR恢复。
