# AD9233 50 Ω 模块：25 MSPS 跑通步骤

本分支是测量分支，ADC 原始采样率为 25 MSPS。不要再按旧文档中的
125 MSPS/128 倍 SignalTap 抽取判断波形。

## 直接对插和供电

AD9233 模块平面旋转 180°，占用扩展口第 6～17 行：

| 行 | FPGA 左 | FPGA 右 | AD9233 |
|---:|---|---|---|
| 6 | T4 | R3 | CSB / SCLK |
| 7 | T5 | R4 | SDIO / OTR |
| 8 | T6 | R5 | D11 / D10 |
| 9 | T7 | R6 | D9 / D8 |
| 10 | T8 | R7 | D7 / D6 |
| 11 | T9 | R8 | D5 / D4 |
| 12 | T10 | R9 | D3 / D2 |
| 13 | T11 | R10 | D1 / D0 |
| 14 | G2 | R11 | DCO / OEB |
| 15 | T13 | R12 | ADC CLK / PWDN |
| 16 | T14 | R13 | GND / GND |
| 17 | N6 | R14 | +5V / +5V |

T14、R13、N6、R14 必须不发生机械接触。模块 5 V 和 GND 用短线单独
引出，其中 GND 必须与 FPGA 共地。严禁让模块 5 V 接触 N6/R14 FPGA IO。

50 Ω 版 SMA 内部已有 50 Ω 终端，不要在 SMA 处再并一个 50 Ω。

## 下载与 SignalTap

下载文件：

`prj/DAC904_HighSpeedDAC.sof`

SignalTap 文件：

`debug/ad9233_capture.stp`

SignalTap 现在直接用 DCO 采集每个原始点：

- 采样率：25 MSPS
- 深度：4096
- 时间窗口：163.84 µs
- 100 kHz：约 250 点/周期
- 500 kHz：约 50 点/周期

将 `adc_debug_sample_o[11:0]` 设置为 Signed Decimal 或 Analog。

| 状态位 | 含义 |
|---|---|
| `[0]` | 固定 1，确认采集时钟运行 |
| `[1]` | 当前原始 OTR |
| `[2]` | ADC SPI 配置完成 |
| `[3]` | 25 MHz PLL 锁定 |
| `[9]` | MCU SPI 请求 CRC 曾错误 |
| `[10]` | 4096 点帧正在采集 |
| `[11]` | 冻结帧已就绪 |

## F0 验收

1. 先不接滤波器和放大器。
2. 信号源设 `Load=50 Ω`，用同轴线直接接 ADC SMA。
3. H2-3 和 H2-4 均应约 25 MHz。
4. SignalTap 中 `[3]=1`、`[2]=1`、OTR=0。
5. 输入 100 kHz、1 Vpp 正弦，码值峰峰值约 410。
6. 输入 100 kHz 三角波，码值应连续单调，不能出现固定折返位。
7. 输入 500 kHz、1 Vpp 正弦，应约 50 点/周期。
8. 分别测 0.5、1、2 Vpp，码值峰峰值应约 205、410、819，允许模块
   实际增益误差，但三者比例应接近 1:2:4。
9. 连续采集 100 次，OTR=0，周期和幅度无随机跳变。

若不通过，按电源/共地、25 MHz CLK、DCO、模块方向、D0～D11 映射、
ADC SPI 配置的顺序检查，先不要进入 MCU/FFT 调试。

T13 不是 PLL 专用时钟输出脚，这是为直接对插做的取舍。Quartus 会报告
非专用布线警告。出现随机跳码或 DCO 不稳时，应改转接板并把 ADC CLK
移到专用 PLL 输出脚。
